## Database Query Changes

### Before
```sql
❌ WRONG TABLE:
LEFT JOIN products p ON it.product_id = p.id
-- "products" table doesn't exist for inventory items
```

### After
```sql
✅ CORRECT TABLE:
LEFT JOIN inventory p ON it.product_id = p.id
-- "inventory" table contains actual product data
```

## Database Schema Clarity

### What Gets Recorded Where

```
SALES TRANSACTION FLOW:
User Records Sale
        ↓
Creates inventory_transactions
├─ Type: "out"
├─ Product: Which item sold
├─ Quantity: How many sold
├─ Timestamp: When
└─ User: Who recorded it

Creates sales_transactions
├─ Amount: Total sale
├─ Date: Sale date
├─ Notes: Description
├─ Timestamp: When
└─ User: Who recorded it

Updates inventory
└─ Quantity: -[amount sold]
```

## Visual Summary: How Transactions Flow

### SCENARIO: CUSTOMER BUYS 5 COLORED BONDPAPERS

```
STEP 1: STAFF RECORDS SALE
┌─────────────────────┐
│  Staff Dashboard    │

           ↓
STEP 2: SYSTEM PROCESSES
┌─────────────────────┐
│  Application Logic  │
│  Validates data     │
│  Calculates totals  │
│  Starts transaction │
└──────────┬──────────┘
           ↓
STEP 3: DATABASE UPDATES
```
