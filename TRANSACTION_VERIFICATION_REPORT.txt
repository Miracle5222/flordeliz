## How Transactions Are Recorded

### Inventory Module
```
When: User adds new product/material
File: staff/inventory/add.php (line 43+)
Creates: inventory_transactions (type='in')
Records:
  - product_id
  - transaction_type = 'in'
  - quantity
  - notes: "Added new inventory item: [name]"
  - created_by (from $_SESSION['user_id'])
  - created_at (auto timestamp)
```

### Sales Module
```
When: User records a sale
File: staff/sales/create.php (line 107+)
Creates TWO records:
  
  1. sales_transactions
     - transaction_date
     - total_sales
     - notes: "Sale recorded for [product]"
     - created_by (from $_SESSION['user_id'])
     - created_at (auto timestamp)
  
  2. inventory_transactions
     - product_id
     - transaction_type = 'out'
     - quantity
     - notes: "Sold [qty] [unit] of [product]"
     - created_by (from $_SESSION['user_id'])
     - created_at (auto timestamp)

Also Updates:
  3. inventory table
     - quantity = quantity - [amount sold]
```
